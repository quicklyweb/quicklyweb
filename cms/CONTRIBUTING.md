# Contributing to the Modular PHP CMS

Thank you for your interest in contributing!

## Guidelines

- Only well-documented and clearly scoped pull requests will be considered
- All code **must be commented** for clarity and future maintainability
- Follow the coding style already used in the project (basic PSR-12)
- Issues and suggestions are welcome, but final implementation is always decided by the maintainer

## Maintainer

This project is solely maintained by **Murat Anur**. No changes will be merged without approval.

Thank you for respecting the direction and vision of this project.
